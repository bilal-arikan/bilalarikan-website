Simple Mini Map package includes the easy-to-use MiniMap feature. It contains very little code.

https://github.com/bilal-arikan/UnitySimpleMiniMap

https://assetstore.unity.com/packages/slug/226420

  • You can import MiniMapDemo.unitypackage to review the example in the video
  • How to Use:
var minimap = FindObjectOfType<Arikan.MiniMapView>();

// Red object example
var img = minimap.FollowCentered(obj1Centered.transform);
img.color = obj1Centered.material.color;

// Green object example
var img2 = minimap.Follow(obj2.transform);
img2.color = obj2.material.color;

// Blue object example
var img3 = minimap.Follow(obj3.transform, obj3Sprite);
img3.color = obj3.material.color;
